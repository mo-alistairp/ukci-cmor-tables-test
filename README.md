# UKCI proof of concept

This is an initial set up of the MIP tables for UKCI use with CMOR and CDDS. 

# CMOR tables for UKCI

The tables here were forked from the [MetOffice/arise-cmor-tables](https://github.com/MetOffice/arise-cmor-tables) repository and adapted to allow data to be output for the UKCI project. The changes made to the MIP tables are restricted to the mip era, with changes related to the activity id (`UKCI`), license text and experiment id (`To be decided`) made to the CVs file.
